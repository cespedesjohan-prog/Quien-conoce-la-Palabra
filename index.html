¿Quién conoce la Palabra?

60 preguntas de 2 Timoteo · 4 rondas de 15 preguntas para participantes o grupos

🎤 Soy el presentador

Crea una sala, comparte el código y controla las preguntas desde tu computador o celular.

Estos datos se usan en tu navegador. No pegues aquí una clave secreta de servidor (service_role).

📱 Soy participante

Escribe el código de la sala y tu nombre para responder desde tu propio dispositivo.

Usa el mismo código, URL y clave pública del presentador. Mantén abierta la pestaña del presentador.

👥 Soy público

Ingresa a la sala para votar cuando el presentador active el comodín «El público». Esta pantalla es solo para votar; no permite responder las preguntas del concurso.

Antes de jugar

Esta versión usa Supabase Realtime Broadcast para sincronizar preguntas, respuestas y votos entre dispositivos. Necesitas crear un proyecto gratuito en Supabase y pegar su URL y clave pública. No hace falta crear tablas: los mensajes se transmiten por una sala pública identificada por un código aleatorio. Comparte el código solo con tu grupo. Enlaces directos: añade ?rol=presentador, ?rol=jugador o ?rol=publico al final de la dirección web.

La conexión se establece desde el navegador.
